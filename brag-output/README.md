# brag-output

Source for the demo video embedded in the root `README.md`. Generated by the
`/brag` skill; the rendered `brag.mp4` and its poster also live at `docs/` on `main`.

| Path | What it is |
|---|---|
| `brag-plan.md` | Creative contract — angle, storyboard, beat locks, visual identity |
| `composition-brief.md` | Handoff brief given to Hyperframes |
| `share-copy.txt` | Caption for posting |
| `composition/index.html` | The composition (7 scenes, one paused GSAP timeline, 23.4s) |
| `composition/scripts/generate_brain.py` | Renders the thresholded cortical heatmap PNGs |
| `composition/assets/brain/` | `brain-a/b/c.png` — three activation states, cross-faded |
| `composition/assets/music/`, `assets/sfx/` | Bundled audio from the `/brag` skill (Kenney SFX; music by ende.app) |

## Rebuilding

This machine has no `ffmpeg`, `unzip`, or system Chrome, and `sudo` needs a
password. Both are worked around without installing anything:

```bash
export HYPERFRAMES_BROWSER_PATH="$HOME/.cache/ms-playwright/chromium_headless_shell-1237/chrome-headless-shell-linux64/chrome-headless-shell"
cd brag-output/composition && npm run check
```

```bash
npx hyperframes render . --docker --quality looks --fps 30 -o ../brag.mp4
```

`--docker` supplies ffmpeg. Do not use Playwright's bundled ffmpeg — it is a
`--disable-everything` build with no H.264.

To regenerate the brain art (needs numpy + Pillow):

```bash
python3 brag-output/composition/scripts/generate_brain.py
```
